# Briselle AI Engineering Standard (BAIES) v1.0 - Enterprise Architecture

## Purpose
Mandatory architecture standards for Briselle.

## Core Principles
- Business-first
- Metadata-driven
- Configuration over customization
- Composition over inheritance
- SOLID
- Backward compatibility

## Mandatory Rules
- Modular features
- No duplicated logic
- No inline CSS
- No circular dependencies
- Repository/service access for persistence
- Document public interfaces

## AI Rules
- Modify only impacted code
- Reuse existing components
- Stop after two unsuccessful investigation loops
- Never fabricate APIs
- Require approval for breaking changes

## Review Checklist
- Architecture
- Security
- Performance
- Documentation
- Manual testing
